## Description (verbatim raw markdown)

Detectado durante la pasada de QA del ticket #89.

**Reporte:** Inventory — Lot Detail (`report_inventory_detailed`, slug `inventory-detailed`).

**Problema:** la columna `is_expired` llega como NULL (se muestra como celda vacía) para los lotes que no tienen fecha de vencimiento (`lots.expires_on IS NULL`). La expresión SQL `l.expires_on < current_date` devuelve NULL cuando `expires_on` es NULL.

**Esperado:** un lote sin fecha de vencimiento no está vencido, debería mostrar `false` (No).

**Impacto:** menor / cosmético. El tipo compuesto SQL `report_inventory_detailed_row` y el tipo TypeScript `ReportInventoryDetailedRow` declaran `is_expired` como booleano no-nulo, así que además es una inconsistencia de tipos.

**Fix sugerido:** en `report_inventory_detailed()` envolver con `coalesce(l.expires_on < current_date, false)`. Requiere una migración nueva (re-crear la función). Es preexistente, no fue introducido por #92.

No es bloqueante. Los otros 9 reportes pasaron QA sin problemas.
